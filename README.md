# Marketing Automation with n8n

## Project Overview
Designed an automated workflow to streamline Meta Ads performance reporting using n8n, AI-assisted analysis, PDF generation, and Slack delivery.

## Problem Statement
Manual campaign reporting can involve repetitive data collection, performance analysis, formatting, and report distribution.

## My Role
Digital Marketing Executive — workflow design, marketing performance analysis, and reporting automation.

## Workflow Architecture
1. **Data retrieval:** Retrieve campaign performance data through the Meta Marketing API.
2. **Data processing:** Organise metrics such as spend, impressions, clicks, CTR, CPC, and CPL.
3. **AI-assisted analysis:** Generate performance observations and optimisation insights from the available data.
4. **Report generation:** Format the output into a PDF report.
5. **Delivery:** Send the generated report to Slack.

## Tools Used
- n8n — workflow automation
- Meta Marketing API — campaign data retrieval
- AI model — performance insight generation
- PDF generation service — report formatting
- Slack — report delivery

## Business Value
- Reduced repetitive reporting steps through automation.
- Combined campaign metrics and AI-assisted analysis in one report.
- Made campaign reporting easier to distribute and review.
